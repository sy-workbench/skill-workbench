# Settings for md-to-html

How to use this file: copy it, rename the copy to `settings.md` (same folder), and fill in the copy. Do not edit this example, so that updating the skill can replace it safely. This skill's README in the skill-workbench repo explains each value.

Everything here is optional. Delete a line, or leave it as it is, to use the default.

Theme used when you do not name one (a file name in `assets/themes/` without `.css`, or a path to your own `.css` file; default `default`):
Default theme: <YOUR_DEFAULT_THEME>

Language code written into the page, which affects fonts and screen readers (for example `en`, `zh-Hant`, `ja`; default `en`):
Page language: <YOUR_PAGE_LANGUAGE>
