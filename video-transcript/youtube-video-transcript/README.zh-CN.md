# youtube-video-transcript

[English](README.md) | [繁體中文](README.zh-TW.md) | 简体中文

版本 1.0，最后更新 2026-11-18。

我从视频学到很多东西，但我想要能搜索、引用、做笔记，而很多视频没有字幕，或只有粗糙的自动字幕。这个 skill 会把 YouTube 视频转成文字文字稿：只下载音频，在你自己的电脑上用 Whisper 转录，视频本身的字幕放在旁边当对照，最后由 agent 修正语音识别常听错的专有名词（例如把产品名“Codex”听成“CoreDesk”）。

如果视频本来就有不错的字幕，用字幕工具就能拿到你要的内容，那样比较快。这个 skill 是给那些做不到的时候用的。

## 需求

在运行转录的那台电脑上：

- Python 3.9 以上。
- yt-dlp，用来下载音频和字幕。
- 给 yt-dlp 用的 JavaScript 运行环境，现在下载 YouTube 需要它。yt-dlp 建议用 Deno。
- openai-whisper，在本机做转录。第一次运行会下载模型。
- ffmpeg（内含 ffprobe），让 Whisper 读得了音频。

以 macOS 加 Homebrew 为例：`brew install yt-dlp deno ffmpeg pipx`，再 `pipx install openai-whisper`。Homebrew 管理的 Python 可能会拒绝直接 `pip install`，所以示例用 pipx。也可以请 agent 帮你检查和安装。

不需要账号、登录或 cookies，所以私人视频、会员限定和有年龄限制的视频不支持。

## 设置

把整个 skill 文件夹（含 `scripts/`）复制到 agent 的 skills 目录（位置依工具而定）。

可选：把 `settings.example.md` 在同一个文件夹复制成 `settings.md`，可以改这些默认值：

- 输出文件夹：文字稿放哪里，每个视频一个子文件夹。默认 `~/video-transcripts`。
- Whisper 模型：默认 `small`，速度和准确度比较平衡。`medium`、`large` 比较准，但慢很多。
- 字幕语言：向 YouTube 要哪些语言的字幕，用逗号分隔。默认 `en,en-orig`。把你常看的语言加进去，例如 `en,en-orig,ja,zh-Hant`。只会留下和视频原语言相同的字幕。
- 谁来运行 script：`me`（默认）是 agent 给你一行指令，你贴到终端运行。`agent` 是 agent 自己跑，前提是它能在你的电脑上运行指令、有网络，而且能等很久。

## 用法

粘贴 YouTube 链接，说要文字稿。默认情况下，agent 会给你一行指令，贴到终端运行。跑完告诉 agent，它会读结果、修正专有名词，再告诉你文件在哪里。

每个视频一个文件夹，里面有原始文字稿、修正稿、一份记录改了什么和依据的 `corrections.md`、有字幕的话也有字幕，还有音频。之后再问同一个视频，agent 会直接从这个文件夹回答，不会重新下载。

用 `small` 模型大约需要视频长度的 0.4 倍时间。如果 Whisper 卡在同一句一直重复，script 会换个设置再跑一次，时间可能接近加倍。更大的模型会慢好几倍；script 的时间上限会跟着模型调整，超时不会算成视频下载失败。

## 怎么兼容不同平台

script 刻意拆成两半：

- **下载**：每个平台不同。YouTube 是一次 yt-dlp 调用，拿到音频、字幕和元数据（标题、简介、标签）。
- **转录和修正**：不管视频从哪里来。它只需要一个音频文件，加上一小份来源描述（平台、ID、标题、作者、链接、简介、标签、语言），剩下的都一样：Whisper、重复时重跑、输出文件、更新索引。

`SKILL.md` 里的修正规则也是同样的拆法。要修什么、什么绝对不改、各种证据的强弱，在每个平台都一样。唯一和平台有关的，是有哪些对照来源可以用：YouTube 有标题、简介、标签、章节名称和字幕。

想支持其他网站，就写一个下载函数，生成上面说的音频文件和来源描述，再交给 `scripts/yt_transcript.py` 里的 `transcribe()`。输出文件夹、索引和修正步骤都不用改，所有文字稿不管来源，都会放在同一个地方。

## 补充

- script 不会自己重试。下载失败就停下来说明原因；同一个视频 24 小时内失败两次，在你明确要求之前都会拒绝再跑。这是为了避免频繁请求 YouTube 而被暂时封禁。
- yt-dlp 要不时更新，因为 YouTube 常改版。yt-dlp 太旧是下载失败最常见的原因。
- 文字稿和字幕都是机器生成的。修正步骤只改专有名词和明显的同音错字，没把握的会列出来，不会乱猜。
- 不翻译：英文视频就是英文文字稿。
- 每次运行都会写 log 到 `/tmp/yt_transcript.log`。

## 升级到新版本

换掉 skill 文件夹时，你的 `settings.md` 可能会一起被删掉。升级前先复制到其他地方，升级完再搬回来。文字稿放在 skill 之外的输出文件夹，不受影响。

如果新版需要新的设置，`CHANGELOG.md` 会写明。

## 在云端或手机上运行

转录要在装好上面那些工具的电脑上跑，所以手机 app 和大部分云端沙箱都不能运行，它们通常也没有网络可以下载。在手机上还是可以先要到指令，之后回电脑再跑。如果环境只保存 `SKILL.md`，把 `settings.md` 的内容贴到 `SKILL.md` 最后面，标题用 `## Settings (pasted)`，每次升级后要重贴。
