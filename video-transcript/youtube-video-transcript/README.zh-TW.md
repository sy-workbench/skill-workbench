# youtube-video-transcript

[English](README.md) | 繁體中文 | [简体中文](README.zh-CN.md)

版本 1.0，最後更新 2026-11-18。

我從影片學到很多東西，但我想要能搜尋、引用、做筆記，而很多影片沒有字幕，或只有粗糙的自動字幕。這個 skill 會把 YouTube 影片轉成文字逐字稿：只下載音訊，在你自己的電腦上用 Whisper 轉錄，影片本身的字幕放在旁邊當對照，最後由 agent 修正語音辨識常聽錯的專有名詞（例如把產品名「Codex」聽成「CoreDesk」）。

如果影片本來就有不錯的字幕，用字幕工具就能拿到你要的內容，那樣比較快。這個 skill 是給那些做不到的時候用的。

## 需求

在執行轉錄的那台電腦上：

- Python 3.9 以上。
- yt-dlp，用來下載音訊和字幕。
- 給 yt-dlp 用的 JavaScript 執行環境，現在下載 YouTube 需要它。yt-dlp 建議用 Deno。
- openai-whisper，在本機做轉錄。第一次執行會下載模型。
- ffmpeg（內含 ffprobe），讓 Whisper 讀得了音訊。

以 macOS 加 Homebrew 為例：`brew install yt-dlp deno ffmpeg pipx`，再 `pipx install openai-whisper`。Homebrew 管理的 Python 可能會拒絕直接 `pip install`，所以範例用 pipx。也可以請 agent 幫你檢查和安裝。

不需要帳號、登入或 cookies，所以私人影片、會員限定和有年齡限制的影片不支援。

## 設定

把整個 skill 資料夾（含 `scripts/`）複製到 agent 的 skills 目錄（位置依工具而定）。

選填：把 `settings.example.md` 在同一個資料夾複製成 `settings.md`，可以改這些預設值：

- 輸出資料夾：逐字稿放哪裡，每支影片一個子資料夾。預設 `~/video-transcripts`。
- Whisper 模型：預設 `small`，速度和準確度比較平衡。`medium`、`large` 比較準，但慢很多。
- 字幕語言：向 YouTube 要哪些語言的字幕，用逗號分隔。預設 `en,en-orig`。把你常看的語言加進去，例如 `en,en-orig,ja,zh-Hant`。只會留下和影片原語言相同的字幕。
- 誰來執行 script：`me`（預設）是 agent 給你一行指令，你貼到終端機執行。`agent` 是 agent 自己跑，前提是它能在你的電腦上執行指令、有網路，而且能等很久。

## 用法

貼上 YouTube 連結，說要逐字稿。預設情況下，agent 會給你一行指令，貼到終端機執行。跑完告訴 agent，它會讀結果、修正專有名詞，再告訴你檔案在哪裡。

每支影片一個資料夾，裡面有原始逐字稿、修正稿、一份記錄改了什麼和依據的 `corrections.md`、有字幕的話也有字幕，還有音訊。之後再問同一支影片，agent 會直接從這個資料夾回答，不會重新下載。

用 `small` 模型大約需要影片長度的 0.4 倍時間。如果 Whisper 卡在同一句一直重複，script 會換個設定再跑一次，時間可能接近加倍。更大的模型會慢好幾倍；script 的時間上限會跟著模型調整，超時不會算成影片下載失敗。

## 怎麼兼容不同平台

script 刻意拆成兩半：

- **下載**：每個平台不同。YouTube 是一次 yt-dlp 呼叫，拿到音訊、字幕和中繼資料（標題、說明、標籤）。
- **轉錄和修正**：不管影片從哪裡來。它只需要一個音訊檔，加上一小份來源描述（平台、ID、標題、作者、連結、說明、標籤、語言），剩下的都一樣：Whisper、重複時重跑、輸出檔案、更新索引。

`SKILL.md` 裡的修正規則也是同樣的拆法。要修什麼、什麼絕對不改、各種證據的強弱，在每個平台都一樣。唯一和平台有關的，是有哪些對照來源可以用：YouTube 有標題、說明、標籤、章節名稱和字幕。

想支援其他網站，就寫一個下載函式，產出上面說的音訊檔和來源描述，再交給 `scripts/yt_transcript.py` 裡的 `transcribe()`。輸出資料夾、索引和修正步驟都不用改，所有逐字稿不管來源，都會放在同一個地方。

## 補充

- script 不會自己重試。下載失敗就停下來說明原因；同一支影片 24 小時內失敗兩次，在你明確要求之前都會拒絕再跑。這是為了避免頻繁請求 YouTube 而被暫時封鎖。
- yt-dlp 要不時更新，因為 YouTube 常改版。yt-dlp 太舊是下載失敗最常見的原因。
- 逐字稿和字幕都是機器產生的。修正步驟只改專有名詞和明顯的同音錯字，沒把握的會列出來，不會亂猜。
- 不翻譯：英文影片就是英文逐字稿。
- 每次執行都會寫 log 到 `/tmp/yt_transcript.log`。

## 升級到新版本

換掉 skill 資料夾時，你的 `settings.md` 可能會一起被刪掉。升級前先複製到其他地方，升級完再搬回來。逐字稿放在 skill 之外的輸出資料夾，不受影響。

如果新版需要新的設定，`CHANGELOG.md` 會寫明。

## 在雲端或手機上執行

轉錄要在裝好上面那些工具的電腦上跑，所以手機 app 和大部分雲端沙盒都不能執行，它們通常也沒有網路可以下載。在手機上還是可以先要到指令，之後回電腦再跑。如果環境只保存 `SKILL.md`，把 `settings.md` 的內容貼到 `SKILL.md` 最後面，標題用 `## Settings (pasted)`，每次升級後要重貼。
