# agent-inbox-pusher

Version 1.3. Last updated 2026-11-11. Part of [agent-inbox](../README.md).

Saves the current session's discussion as an entry in your Notion Agent Inbox, so another agent (or you, on another device) can pick it up later. It can also skip Notion and print a handoff prompt for a new session (Mode B). What it does, which phrases to say, the requirements, setup, upgrading, and running in the cloud or on a phone are all in the [agent-inbox README](../README.md).

## Also good to know

- In Mode A (Notion), the skill first shows you a draft with four sections (Background / Problem / Resolution / Next Step), plus Type and Handover To. It writes to Notion only after you confirm.
- In Mode B (paste), it prints one code block for you to paste into a new session. It writes nothing.
